# Common Lisp

This version of VICEtoPS was written in the [ANSI Common Lisp](https://secure.wikimedia.org/wikipedia/en/wiki/Common_Lisp) programming language.

## Usage

Execute `vicetops.lisp` in your Common Lisp environment and it will ask for upper or lower case and VICE output filename. The PostScript filename will be out.ps.
