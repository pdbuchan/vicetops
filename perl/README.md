# perl

This version of VICEtoPS was written in the [Perl](https://secure.wikimedia.org/wikipedia/en/wiki/Perl) programming language.

## Usage

At the command line, type the following for usage instructions:

```sh
perl ./vicetops.pl
```

or make `vicetops.pl` executable:

```sh
chmod u+x vicetops.pl
```

and then run:

```sh
./vicetops.pl
```
